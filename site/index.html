Visual Typist

A keyboard-first visual equation editor for macOS. Type math in a WYSIWYG canvas, switch to the LaTeX code at any time, and export to PDF, PNG, SVG, LaTeX or MathML.

Try it in your browser Build the Mac app Source on GitHub

The browser edition runs the same editor as the app; the app adds PDF export, rich clipboard images and keeps your input method out of the way.

What it does

Structured editing

Fractions, roots, scripts, integrals and matrices with slots you move between by keyboard, like a classic equation editor.

Commands as you type

Type \mu, \frac or \sum and pick from a candidate bar, the way an input method works.

Live LaTeX

The code pane and the equation stay in sync; brackets are paired and highlighted in both.

Shortcuts for everything

Windows equation-editor habits carry over: Ctrl becomes ⌘ and Alt becomes ⌥. Any palette button can get its own shortcut.

Clean output

Standard LaTeX, staggered tensor indices, vector PDF and SVG, PNG at any scale, MathML.

Native and offline

A small Apple Silicon app for macOS 14 or later, with light and dark themes. Nothing leaves your Mac.

Get the Mac app

Clone the repository and run one command. It checks the toolchain, repairs or installs what is missing (asking first), builds the app, installs it into /Applications and opens it.

git clone https://github.com/HaiXuan-Lin/Visual-Typist.git
cd Visual-Typist
./build.sh --install

Requires an Apple Silicon Mac with macOS 14 or later. The app is signed ad hoc for local use.

A few shortcuts

⌘F ⌘RFraction, square root
⌘Q ⌘L ⌘JSuperscript, subscript, both
⇧⌘I ⇧⌘SIntegral, sum with limits
( [ {A pair of brackets, or brackets around the selection
\ + name, SpaceType a command and take the first candidate
⌃⇥Switch between the symbol palette and the LaTeX code
⌘C ⌘TCopy as image, copy LaTeX

In the browser on Windows or Linux, use Ctrl for ⌘ and Alt for ⌥. Some combinations (such as Ctrl+N, Ctrl+T, Ctrl+W) belong to the browser.
